# Sales & Product Performance Analysis | Power BI

## Project Overview
This is a personal Power BI data analytics project using sample sales data to analyze sales performance, profitability, product performance, and sales targets.

## Tools & Skills
- Power BI Desktop
- DAX Measures
- Data Modeling & Table Relationships
- Data Visualization
- KPI Reporting
- Top N Filtering
- Interactive Slicers

## Dashboard Pages

### 1. Executive Overview
- Total Sales, Total Profit, Profit Margin, and Total Units
- Sales Target Achievement
- Monthly Sales Trends
- Sales and Profit by Category
- Actual Sales vs. Monthly Targets

### 2. Product Performance Analysis
- Total Products
- Average Sales and Profit per Product
- Top 10 Products: Sales vs. Profit
- Top 10 Products by Profit Margin
- Top 10 Products by Units Sold
- Interactive Category Filtering

## Project File
Open `project1.pbix` using Power BI Desktop to explore the interactive report.

## Data
This project uses sample data for learning and portfolio purposes.
